# GBD溯源、25岁及以上人口与地理标记核验

核验日期：2026年10月5日。仅在“03 成人哮喘与吸入药物/正式分析”新增交付文件；没有修改既有V1、原GBD导出、既有地图或其他论文稿件。

**结论：人口文件可直接用于正式分析；原数据属于GBD 2023导出有较强且相互一致的来源证据，但原citation中的2024数据集出版年份尚未独立确认；数据集与方法论文可以使用不同出版年，不能仅据2025年方法论文判断原日期错误。168国平衡样本中的19个旧地图标记不构成删除国家统计的依据。**

## 2. 25岁及以上人口交付及一致性

交付：`输入数据/成人哮喘人口.csv`，UTF-8 BOM，2,448行；204个国家和地区×2010—2021年。键为`iso3, year`且无重复。主要列为`iso3`、`year`、`pop25`、`source`，另保留GBD location ID、国家名、年龄ID/标签、性别ID、人口上下界和原文件路径。

只选原始人口文件的`age_id=157`（原标签“25年以上”），`sex_id=3`（两性合计），`measure_id=44`（人口数），`metric_id=1`（数量）。**不是把25+和65—69等重叠年龄组相加。** 人口上下界是原25+汇总行自带的区间，未通过相加年龄组区间制造。

核验按GBD `location_id + year`先对接，再带入ISO3，不按模糊国家名称匹配。对全部2,448个国家年计算：

\[
\widehat{N}_{25+}=\frac{\operatorname{DALY\ Number}_{25+}}{\operatorname{DALY\ Rate}_{25+}}\times100000.
\]

全部条目同时具有DALY数、DALY率和人口；最大相对差异为**2.1654×10⁻¹⁵**，以10⁻⁸为容差的失败数为0，人口自身满足`lower ≤ value ≤ upper`。逐行结果见`成人哮喘人口一致性.csv`。

这证明点估计的数—率—人口分母一致，不能由此推断DALY和人口不确定性相互独立，也不能直接用区间端点做联合抽样。**当前“adult DALY rate”是25岁及以上汇总人群的粗率（每10万人），不是年龄标化率。** 跨国比较时成年内部年龄结构仍可能影响率，正式文稿、图轴和模型解释必须使用准确名称。WHO药物字段本身仍是国家总体服务能力，并不限制为25+患者；研究的成人年龄限制落在所联结负担和人口上。

## 3. 19个旧地图标记的逐项复核

旧`TableS18_geography_crosswalk.csv`共204行，其中23行`review_required`；与当前WHO调查框架相交为21行，与168国平衡样本相交为19行。后两者差异来自中国和哈萨克斯坦在当前平衡药品样本之外；原23行中巴勒斯坦、托克劳不在当前WHO调查框架。不能把“原来23、现在19”描述成已经解决了4个统计错误。

19行均有明确GBD level-3 location ID和国家名称、WHO国家代码和名称，并能进行国家统计身份匹配。它们的旧标记来源如下：

|---|---|---|---|

“保留”表示**这些旧标记没有证明国家统计记录无效**，并不表示本次已经认证GBD、WHO和环境资料对所有争议地区/海外领地的覆盖完全相同。匹配国家身份与证明完全相同的空间支持是两个不同检查。逐国保留原标记、原图形片段、原备注、WHO名称、GBD ID及新处理结论，见`GBD溯源与地理核验.csv`（204行，便于完整审计）。

对当前使用WHO/世界银行现成国家环境指标、国家药品调查和GBD国家负担的分析，**主样本不应因这19个标记从168降到149**。如果绘制填色地图，形状选择属于单独的展示环节；对边界敏感情况可以明确地图说明或改用国家点图/条形图。如果后续重新从网格聚合环境暴露，空间边界会真正参与变量生成，届时需要单独验证这些边界，而不能沿用“国家ID已匹配”替代空间支持验证。

可选的“排除旧地图范围标记”敏感性分析必须注明它是保守的制图范围诊断，不能标为“剔除匹配失败/无效国家后的主分析”，也不能把剩下149国声称为唯一可信样本。
