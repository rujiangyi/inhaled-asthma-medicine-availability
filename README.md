# Source data

This archive contains exactly 68 analytical/source CSV files: nineteen frozen statistical tables (Statistics), forty-three frozen figure-source tables (Figures) and six additional machine-readable tables (Additional). These are copies of V3 and the submission supplement, not regenerated selections. Inventory.json records row counts, schemas, descriptions and SHA256 hashes. Data dictionary.md defines the principal fields and denominator conventions. Sources.md describes provenance and reuse conditions.

No blanket open licence is assigned. IHME-derived values remain subject to their applicable conditions even in a derived table. This local attachment has not been deposited in a public repository and is not a certificate of redistribution permission. There are no patient-level records in this archive.

The companion Analysis code.zip contains the frozen reduced inputs and portable scripts for nineteen statistical tables and eleven composite figures. The four main-figure scripts include the latest legend changes. CSV source values are unchanged by those visual changes. The six additional files collect existing outputs for convenient use; they do not add new fitted models.
